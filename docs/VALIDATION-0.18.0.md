# Проверки тестовой версии 0.18.0

База: опубликованный 0.17.0, коммит `6c504599cf697677065a8584f420a98a7c73aed2`.
Сборка 0.18.0 подготовлена локально, без push и без нового GitHub Release.

- 19 модульных тестов: обновления и контроль URL/SHA-256, журнал и отдельная прочитанность, сохранение отпечатков перевода, настоящий Java-парсер переписи, разбор сохранённого реального ответа публичного Armory, регион/имя и ограничения изображений. Все прошли.
- 64 стартовых билда / 9 классов прошли проверку очков, зависимостей, описаний и атласов.
- Два интеграционных сценария OAuth-сервиса с тестовым upstream: вход, привязка к verifier телефона, одноразовые коды, сеанс, выход и закрытый отказ без настройки. Реальный Battle.net OAuth не проверен и не активирован.
- Сценарии Playwright на 320 и 412 px: отсутствие горизонтального переполнения, крупный текст, поиск/сохранение карточки с тестовым Android-мостом, связь уровня с билдом, восстановление после перезапуска, отдельные отметки записей, избранное, прогресс загрузки. Ошибок JavaScript не было. Это проверка локального интерфейса, не установка на Android.
- Публичная страница Armory и поиск доступны при проверке. Модель профиля содержит экипировку, профессии, характеристики и таланты. Формат подтверждён fixture-тестом Java-парсера.
- Android Lint Release прошёл без ошибок; остались предупреждения о дублировании параметров Gradle/manifest, WebView JavaScript, правилах резервного копирования и вариантах иконки.
- Итоговая release-сборка успешна с JDK 17, Gradle 8.9, SDK 35, Build Tools 35.0.0; для устойчивой сборки используется один worker. `TEST_BUILD=true`, версия `0.18.0`, versionCode `18`, API-сервис Battle.net не настроен.
- APK подписан той же цепочкой публичной серии. Сценарий подписи подтвердил сертификаты для API 26–27, 28–32 и 33–36, а также выравнивание 16 KB и создал SHA-256.

Остаются для телефона: установка поверх 0.17.0, доступность источников именно с
сети пользователя, работа WebView и возврат из системных разрешений. Полная
загрузка более новой версии внутри приложения требует разрешённого будущего
выпуска с номером выше 0.18.0. До этого тестирование интерфейса загрузки использует
состояния тестового моста, а не поддельный релиз на GitHub.

Для живого входа Battle.net нужны API-клиент владельца, HTTPS-сервис из `server/`
и сборка с `-PpulseApiBase=https://...`. Секрет хранится только на сервере.
