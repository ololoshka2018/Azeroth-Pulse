# Проверка на телефоне

1. Установить подписанный APK поверх 0.17.0, не удаляя приложение. Проверить сохранение региона и настроек. Зафиксировать любой отказ Android в обновлении.
2. Открыть «Мой персонаж», выбрать регион, ввести имя и фамилию. Проверить поиск, портрет, экипировку, профессии и время данных. Профиль может появиться только с 10-го уровня после выхода из игры и с задержкой.
3. Добавить второго персонажа. В «Мой билд» выбрать цель и подборку. Перезапустить приложение: выбранный билд должен сохраниться отдельно для каждого героя. После обновления уровня в Armory кнопка «Мой билд» подставляет новый уровень.
4. Открыть «Новости»: переход во вкладку не должен очищать все отметки. Открыть одну новость, сохранить другую, проверить «Избранное» и перезапуск. Отключить интернет и проверить сохранённые данные.
5. Открыть «Таланты»: раскрыть одну запись журнала; остальные отметки должны сохраниться. Проверить порядок очков и описания талантов.
6. Настройки: попробовать крупный текст, закрыть и открыть приложение, проверить чтение длинных названий и кнопок.
7. Обновления: открыть версию в шапке. Сейчас публичный выпуск 0.17.0 старше тестового 0.18.0, поэтому обновление не предлагается. Полный путь загрузки и системной установки проверяется после появления более новой разрешённой версии: прогресс, отмена, проверка подписи, разрешение Android и установка с сохранением данных. Тестовый сервер интерфейса проверяет экран прогресса, а подпись APK проверена Android SDK; реальная установка пока не подтверждена.
8. Вход Battle.net в этом APK не активирован: нужны реквизиты API-клиента и HTTPS-сервис. Публичный поиск от этого не зависит. Сервер и Android-код готовы, OAuth-переход и одноразовые коды проверены с тестовым upstream, а реальный аккаунт — нет.

Перед публикацией: проверить актуальные документы, назначить версию выше исправленной тестовой при изменении APK, настроить секрет подписи для Actions. Процесс публикации имеет явный параметр `publish`, по умолчанию `false`. Сам по себе коммит не выпускает APK.
