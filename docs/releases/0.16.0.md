Первая публичная бета Azeroth Pulse для Android 8 и новее.

- Миры EU и US, перепись персонажей, баланс фракций и высший замеченный уровень.
- Распределение персонажей по расам и классам.
- Билды для девяти классов, описания талантов и порядок прокачки.
- Журнал изменений билдов и отметка на иконке вкладки «Таланты».
- Новости Blizzard на русском, чтение в приложении, перевод и оригинал.
- Последняя известная версия Zygor, история изменений и отметка новой версии.
- Отдельное время проверки каждого блока и сохранённые данные при отсутствии связи.
- Проверка обновлений Azeroth Pulse через GitHub Releases.
- Закрытый ключ публичной серии APK с подтверждённой цепочкой перехода с тестовой подписи.
- Открытые исходники, сборка с закреплёнными версиями инструментов и проверки GitHub Actions.

Для установки скачайте Azeroth-Pulse-0.16.0.apk. Android может предложить проверку Play Protect.

Для Android 9 и новее подготовлена смена подписи с сохранением данных тестовой серии. Для Android 8 используется совместимая прежняя подпись. Цепочка проверена инструментами Android SDK. Установка поверх предыдущей версии на реальном телефоне остаётся частью бета-тестирования.

Статистика показывает замеченных персонажей в выборке. Поле текущего онлайна имеет значение «неизвестен».

Игровая графика принадлежит Blizzard Entertainment. Условия сторонних материалов перечислены в THIRD_PARTY.md.
