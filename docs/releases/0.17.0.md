Обновление Azeroth Pulse 0.17.0 для Android 8 и новее.

- В нижней панели осталось четыре вкладки: Миры, Население, Таланты и Новости.
- Удалены вкладки «Гонка» и Zygor, переход «Лидеры мира», журнал и перевод Zygor.
- Удалена фоновая проверка Zygor и разрешение запуска после перезагрузки устройства.
- При обновлении отменяются фоновая задача и уведомление прежней версии.
- Из карточек миров удалён высший замеченный уровень. Рейтинги персонажей больше не загружаются.
- Сохраняются новости, таланты, журнал изменений билдов и обновления приложения.

APK подписан ключом публичной серии с подтверждённой цепочкой перехода с тестовой подписи. Установка поверх 0.16.0 сохраняет совместимую подпись. Проверка на реальном Android-устройстве остаётся частью бета-тестирования.

Исходники распространяются по MIT. Игровые материалы имеют отдельные условия, указанные в THIRD_PARTY.md.
