Тестовая версия Azeroth Pulse 0.18.0. Публичная публикация ожидает проверки владельцем.

- Добавлен «Мой персонаж»: официальный поиск Blizzard по имени и фамилии, до десяти сохранённых героев, портрет, экипировка, характеристики, профессии, фактическое распределение талантов и даты данных.
- Рекомендуемый билд и уровень сохраняются для каждого персонажа; «Мой билд» выбирает класс героя.
- APK загружается внутри приложения. Проверяются размер, SHA-256, версия, package ID и ожидаемая подпись; установку подтверждает Android.
- Исправлен показ английских заголовков до перевода. Добавлены избранные новости.
- Отметки новых новостей и изменений талантов снимаются по отдельным открытым записям.
- Устранены ложные изменения переведённых талантов из-за потери отпечатков описаний.
- Проверки невыбранных классов выполняются реже; шестичасовая проверка APK сохраняет интервал между запусками.
- Добавлены размер текста, источники, лицензии, сведения о статистике и обработке данных в настройках.
- Сохранены четыре основные вкладки и игровой стиль.
- Подготовлены Android-часть и сервер OAuth Battle.net. Для живого входа нужны API-клиент владельца и HTTPS-сервис; в тестовом APK вход не активирован. Публичный поиск работает без логина.

Обновление поверх 0.17.0 и системная установка нового APK требуют проверки на телефоне.
