- Добавлена вкладка «Персонаж». Поиск по имени и фамилии, сохранённые профили, HD-снимок Blizzard, экипировка, характеристики, профессии и таланты.
- В карточках экипировки показывается трансмог. Снимок персонажа статичный, облики указаны в слотах.
- «Персонаж» и «Настройки» доступны в нижней панели. Размер текста можно изменить в настройках.
- Журнал талантов показывает конкретные правки. Старые массовые записи убраны, история билдов сохранена.
- В новостях добавлено избранное, отметки новостей и изменений талантов снимаются при чтении отдельных записей.
- APK можно скачать из приложения. Перед установкой проверяются целостность, версия и подпись файла.

Для проверки обновления с 0.18.3 откройте «Настройки → Обновления → Проверить обновления», скачайте 0.18.4 и подтвердите установку в Android.
