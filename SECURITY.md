# Безопасность

Закрытые ключи подписи, пароли и архив резервной копии подписи храните отдельно от репозитория. Для настройки подписанного выпуска используется секрет GitHub Actions `ANDROID_SIGNING_BUNDLE_BASE64`. Он требуется только отдельной задаче выпуска, запускаемой владельцем из ветки main.

При обнаружении уязвимости, связанной с ключами или личными данными, используйте приватное сообщение об уязвимости GitHub, если эта возможность включена в репозитории. Для воспроизводимой проблемы без чувствительных сведений можно создать Issue. Пароли и ключи в Issues не прикладывайте.

Публичные сертификаты и цепочка смены ключа в `certificates/` предназначены для проверки подписи APK.
