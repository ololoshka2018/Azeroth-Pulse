# Обработка данных

Azeroth Pulse хранит выбранный регион, избранный мир, настройки талантов, отметки просмотренных записей и загруженные материалы в хранилище приложения на устройстве. Очистка хранилища приложения средствами Android удаляет эти данные.

## Сетевые обращения

Для обновления сведений приложение обращается к WoWCensus, Armory WoW Forever, Mobalytics, MmonsteR, METAMMO, Blizzard Entertainment и GitHub. Эти серверы получают обычные сведения сетевого запроса, в том числе IP-адрес и идентификатор клиента. Их обработка определяется правилами соответствующих сервисов.

Проверка новых выпусков использует публичный API GitHub. Нажатие «Обновить приложение» загружает APK из GitHub Releases во внутренний кэш. Файл передаётся системному установщику временным разрешением только на чтение.

Перевод через Google ML Kit выполняется на устройстве. Для первого перевода могут скачиваться языковые модели Google. ML Kit также обрабатывает технические метрики работы SDK согласно условиям Google. [Условия ML Kit](https://developers.google.com/ml-kit/terms).

## Разрешения Android

Приложение использует интернет, сведения о состоянии сети и запрос разрешения на установку APK. Разрешение используется только для обновления самого Azeroth Pulse. Установку загруженного APK и его проверку подтверждает Android.

## Сообщения об ошибках

При отправке сообщения в GitHub Issues содержание сообщения и вложения становятся публичными. Перед отправкой скриншота проверьте, какие имена, уведомления и другие личные сведения видны на нём.

## Персонажи и необязательный вход

Поиск отправляет введённое имя и выбранный регион на официальный сайт Blizzard.
Сохранённые публичные профили, выбранные билды и избранные новости остаются на
телефоне. Изображения загружаются с render.worldofwarcraft.com и кэшируются.
Удаление карточки убирает её из приложения и не изменяет персонажа в игре.

Если владелец активировал вход Battle.net, вход открывается в системном браузере.
Пароль получает только Battle.net. Сервер интеграции получает OAuth-токен с правом
просмотра WoW-профиля и возвращает список персонажей. Токен Blizzard остаётся на
сервере; сеанс приложения защищён Android Keystore. Выход стирает локальный сеанс
и запрашивает удаление серверного. При недоступном сервере остаточный сеанс
истекает не позднее часа. Тестовая сборка без настроенного сервиса не выполняет
OAuth-запросов. Сервер не пишет пароли и токены в журналы.
