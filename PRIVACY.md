# Обработка данных

Azeroth Pulse хранит выбранный регион, избранный мир, настройки талантов, отметки просмотренных записей и загруженные материалы в хранилище приложения на устройстве. Очистка хранилища приложения средствами Android удаляет эти данные.

## Сетевые обращения

Для обновления сведений приложение обращается к WoWCensus, Armory WoW Forever, Mobalytics, MmonsteR, METAMMO, Blizzard Entertainment и GitHub. Эти серверы получают обычные сведения сетевого запроса, в том числе IP-адрес и идентификатор клиента. Их обработка определяется правилами соответствующих сервисов.

Проверка новых выпусков использует публичный API GitHub. Нажатие «Скачать APK» открывает ссылку GitHub Releases в выбранном браузере.

Перевод через Google ML Kit выполняется на устройстве. Для первого перевода могут скачиваться языковые модели Google. ML Kit также обрабатывает технические метрики работы SDK согласно условиям Google. [Условия ML Kit](https://developers.google.com/ml-kit/terms).

## Разрешения Android

Приложение использует интернет и сведения о состоянии сети. Установку загруженного APK и его проверку подтверждает Android.

## Сообщения об ошибках

При отправке сообщения в GitHub Issues содержание сообщения и вложения становятся публичными. Перед отправкой скриншота проверьте, какие имена, уведомления и другие личные сведения видны на нём.
